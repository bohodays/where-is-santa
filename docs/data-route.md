# 경로 데이터 (세계 도시 + 국내 시군구)

산타가 들르는 곳 661곳: 세계 도시 405곳(`src/lib/santa/world-cities.ts`, 자동 생성) + 국내 시군구 256곳(`src/lib/santa/sigungu.ts`, `docs/data-sigungu.md`). 둘을 합치는 곳은 `src/lib/santa/stops.ts`이고, 도착 시각은 화면이 `buildRoute()`로 계산한다(도착 규칙은 `route.ts` 한 곳에만 둔다).

## 결정 (2026-11-21)

| 항목 | 결정 |
|---|---|
| 원본 | [GeoNames cities15000](https://download.geonames.org/export/dump/) (인구 1.5만 이상 도시 약 3.4만 곳, **CC BY 4.0**, 출처 표기 필수) |
| 국내 | GeoNames의 한국 도시는 빼고 시군구 256곳을 모두 넣는다. "우리 동네" 도착 시각이 경로와 정확히 맞는다 |
| 고르는 규칙 | ⓪ 꼭 넣을 곳(키리티마티) ① 수도 전부(240곳) ② 인구 순으로 채우되 **나라당 10곳까지**, 세계 도시 400곳까지 ③ 도시가 없는 **경도 5도 구간**마다 그 구간에서 가장 큰 도시 |
| 빼는 것 | 도시가 아닌 종류(PPLX 도시 안 구역, PPLQ 버려진 곳, PPLH 옛 마을 등), 이미 고른 더 큰 도시에서 **50km 안**(뉴욕의 퀸스, 카이로 옆 기자, 마닐라 옆 케손시티). 수도는 늘 넣는다 |
| 한글 이름 | GeoNames의 한글 이름(`alternatenames`에서 한글만, 뒤의 " 시"는 뗌)이 하나로 모이면 그것. 없거나 여러 개면 `scripts/city-names-ko.json`에 사람이 정한다(국립국어원 외래어 표기법) |
| 나라 | 모든 세계 도시에 한글 나라 이름(`country`)을 둔다. `Intl.DisplayNames("ko")`가 기본이고, 대만·홍콩·마카오·콩고·남아프리카공화국 등은 `city-names-ko.json`의 `countryNames`로 정한다. **대만·홍콩은 '중국'으로 표시하지 않는다** |
| 이름 겹침 | 이름에는 괄호를 넣지 않는다. 이름이 같은 도시(킹스턴, 하이데라바드)와 헷갈리기 쉬운 도시(`showCountry`: 칠레 산티아고, 방글라데시 다카, 세네갈 다카르, 브라질 살바도르)는 화면에서 **나라를 앞에 붙인다**("자메이카 킹스턴", 시군구의 "강원 고성군"과 같은 순서). 나라를 붙여도 겹치면 생성 스크립트가 멈춘다 |
| 시간대 | 2026년 12월 24일 기준 UTC 차이를 Node 내장 `Intl`로 계산(남반구 서머타임, 30·45분 시간대 반영). 새 의존성 없음 |
| 국내 이름 | 특별·광역시의 구·군은 "서울 마포구", 세종은 "세종", 도의 시·군은 그대로("춘천시"), 다른 도에 같은 이름이 있으면 "강원 고성군" |

### 인구 순으로만 고르면 안 되는 이유

인구 상위 500곳을 그대로 고르면 중국이 164곳(33%)이고, 태평양 쪽 경도 5도 구간 20개에 도시가 하나도 없다. 산타가 몇 시간 동안 빈 바다만 난다. 지금 규칙에서는 도시 사이 가장 긴 간격이 58분(화이트호스 → 파페에테)이다.

## 다시 만드는 법

1. [GeoNames 덤프](https://download.geonames.org/export/dump/)에서 `cities15000.zip`을 받아 저장소 바로 아래 `GEONAMES/`에 푼다(`GEONAMES/cities15000.txt`, `.gitignore` 대상, 약 7MB).
2. `npm run build:route`
   - 한글 이름을 정해야 하는 도시가 있으면 목록(GeoNames id, 영어 이름, 후보)을 보여 주고 멈춘다. `scripts/city-names-ko.json`에 적고 다시 실행한다.
   - 이름이 겹치거나, `city-names-ko.json`에 고르지 않은 도시가 남아 있어도 멈춘다.
3. `npm test`로 `src/lib/santa/stops.test.ts`를 확인한다(개수, 이름 겹침, 한글 이름, 시간대 값, 도시 사이 간격 1시간 이하, 국내 도착 시각).

## 검증 (2026-11-21)

- 661곳, id·이름 겹침 없음, 이름 모두 한글
- 여정: 한국 시각 12월 24일 밤 7시 29분 키리티마티(키리바시) 출발 → 25일 밤 8시 22분 파고파고(아메리칸사모아) 끝
- 주요 도시 100곳 한글 이름을 사람이 검수(2026-11-21). 살바도르(사우바도르에서 바꿈), 키이우(키예프 아님), 치타공(영문 공식 명칭은 2018년 Chattogram, 국내 표기 유지) 등은 `city-names-ko.json`의 `notes`에 근거를 남기고 테스트로 고정했다
- 국내 시군구는 모두 한국 시각 25일 0시 16분~42분
- 운영 빌드에서 데모 주소로 7장면 확인(레이아웃 이동 0, axe 위반 0, 콘솔 오류 0)

## 알려진 한계와 남은 일

- **꼭 넣을 곳:** 실제로 가장 먼저 자정이 되는 키리티마티는 인구가 적어 `cities15000`에 없다. 상징성 때문에 `city-names-ko.json`의 `extra`에 GeoNames `KI.txt`의 섬 중심 마을(London Village, 4030939)을 "키리티마티"로 넣었다. 원본을 다시 받으면 이 값은 그대로 둔다.
- **남북으로 크게 튄다:** 도착 시각이 경도로만 정해져서(도메인 규칙 1), 경도가 가까운 도시는 위도가 멀어도 몇 분 간격으로 들른다(예: 케르겔렌 제도 → 카자흐스탄 쉼켄트, 10,192km를 2분). 지도에 비행 경로를 그릴 때(3~4주차 순서 4번) 보이는 방식을 정해야 한다.
- **첫 화면 크기:** 경로 데이터가 첫 화면 JS에 들어가 110 → 127 kB(gzip 약 17 kB 늘어남). 출발 전 화면은 첫 도시와 우리 동네만 있으면 되므로, 필요하면 지도 단계에서 나눠 불러온다.
- **한글 이름 검수:** 주요 도시 100곳은 사람이 검수했다(2026-11-21). 나머지는 GeoNames 이름을 그대로 쓰고 베타 때 고친다.
