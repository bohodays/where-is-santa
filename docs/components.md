# 컴포넌트 목록

2주차에 확정한 화면 시안(디자인 캔버스 "산타 어디쯤 화면 시안" 1안)을 3~4주차(핵심 기능 구현)와 5주차(공유 카드·데모 모드)의 구현 단위로 나눈 목록이다.
색·글자 크기는 `docs/design-tokens.md`의 토큰만 쓰고, 컴포넌트마다 같은 PR에서 스토리를 추가한다(CLAUDE.md).

- **서버/클라이언트:** CLAUDE.md대로 서버 컴포넌트가 기본이다. 상태·브라우저 API·시각이 필요할 때만 `'use client'`.
- **시각:** 글자로 보여주는 시각은 `useNow()`, 프레임마다 움직이는 것은 `useClock()`. 산타 위치는 `santaAt()`로만 계산한다.
- **주차:** 기획서 일정 기준. 3~4주차 = 11/23~12/6 핵심 기능 구현(경로 데이터 생성 스크립트, 지도, 카운트다운, 동네 선택), 5주차 = 12/7~13 공유 카드·데모 모드, 12/13 MVP 배포.

**`MainScreen`(클라이언트):** 현재 시각을 읽는 유일한 곳(`useNow`). `santaAt`의 상태로 위쪽을 고른다: 출발 전·끝난 뒤는 `NorthPoleScene`, 여정 중은 지도 자리 + `SantaLocationBanner`. 아래 고정형 시트에 `CountdownCard`와 `JourneyProgress`(출발 뒤부터). 시트·설정이 아직 없어서 "동네 바꾸기"·"도착 순서 보기"·설정 버튼은 그 동작이 연결될 때(순서 5번) 보인다. 기기 시간대가 한국과 다르면 `showZone`을 켠다.

**경로 나눠 불러오기(2026-11-22):** 첫 화면(북극 마을, 카운트다운, 여정 막대)은 `ROUTE_SUMMARY`만 쓰고 단계는 `journeyPhase`로 정한다. 전체 경로는 출발 10분 전부터 `useRoute`(`src/hooks/useRoute.ts`)가 불러와 `SantaLocationBanner`(그리고 지도)에 넘긴다. 받는 동안 "산타를 찾는 중…", 실패하면 "산타 위치를 불러오지 못했어요"(카운트다운은 그대로).

## 기본 요소

### Button · LinkButton
- **역할:** 주 버튼(`친구에게 알려주기`)과 보조 버튼(`산타 따라가기`). 다른 시트로 가는 것은 `LinkButton`(`<a href>`), 동작은 `Button`(`<button>`).
- **변형:** `primary`(bg-action, text-on-action) · `secondary`(테두리 border, bg-surface) · `quiet`(글자 링크 모양, 예: "동네 바꾸기", "도착 순서 보기").
- **상태:** 기본, 누름, 포커스, 사용 불가, 진행 중(복사 중 등).
- **토큰:** `h-button`, `rounded-button`, `text-body-lg`, `action`, `on-action`, `border`, `link`.
- **접근성:** 높이 52px(quiet는 최소 44px), 포커스 링이 보여야 한다. 아이콘이 있으면 `aria-hidden`.
- **스토리:** 변형 3개 × 상태.

### IconButton
- **역할:** 아이콘만 있는 버튼. 설정(톱니바퀴), 시트 닫기(X).
- **토큰:** `h-touch`, `w-touch`, `rounded-pill`, `shadow-float`(지도 위), `ink`.
- **접근성:** `aria-label` 필수(CLAUDE.md). 44×44px.
- **스토리:** 설정, 닫기, 지도 위/시트 안.

### Switch
- **역할:** 설정의 켜기/끄기(큰 글씨, 고대비, 움직임 줄이기). 소리는 소리 기능을 만들 때(기획서 결정 2026-11-22).
- **상태:** 켜짐(ink), 꺼짐(switch-off), 포커스, 설명 문구 있음("기기 설정을 따라 켜져 있어요").
- **접근성:** `<button role="switch" aria-checked>`, 이름은 옆 글자로 `aria-labelledby`. 꺼짐 색은 흰 바탕과 3:1 이상(토큰 테스트가 검사).
- **스토리:** 켜짐, 꺼짐, 설명 있음, 고대비 모드.
- **구현(2026-11-22):** 한 줄(이름 + 설명 + 스위치)을 그린다. 누르는 칸 44px, 보이는 막대 52×32px. 켜짐/꺼짐은 색과 동그라미 위치로 알린다.

### SegmentedControl
- **역할:** 하나만 고르는 짧은 선택지. 지도 밝기(자동·밝게·어둡게), 데모 시간 흐름(실제 속도·1초=1분·1초=10분).
- **상태:** 선택됨(bg-ink, 흰 글자), 선택 안 됨, 포커스.
- **접근성:** 라디오 그룹(`role="radiogroup"` + `role="radio"` + `aria-checked`, 화살표 키로 이동). 각 칸 높이 46px 이상.
- **스토리:** 지도 밝기, 데모 속도.

### BottomSheet
- **역할:** 아래에서 올라오는 판. 두 가지 쓰임:
  - **고정형:** 메인의 카운트다운 카드. 닫기 없음, 지도 위에 늘 떠 있음.
  - **모달형:** 도착 순서, 동네 고르기, 설정, 공유, 데모. 뒤를 `backdrop`으로 어둡게, 제목과 닫기 버튼.
- **상태:** 열림, 닫힘, 여는 중(애니메이션), 내용이 길어 스크롤.
- **토큰:** `bg-surface`, `rounded-sheet`(위쪽만), `handle`, `backdrop`, `shadow-sheet`.
- **접근성:** 모달형은 `role="dialog"` + `aria-modal` + 제목 연결, 열리면 시트 안으로 포커스, Esc와 닫기로 닫고 연 버튼으로 포커스를 돌려준다. 움직임 줄이기면 애니메이션 없이 바로 열린다.
- **로직:** 어떤 시트가 열렸는지는 쓰는 쪽의 상태(`open`)로 둔다(주소 해시는 쓰지 않는다).
- **뒤로 가기 (결정 2026-11-22):** 휴대폰 "뒤로 가기"는 시트를 닫는다. 열 때 방문 기록에 한 칸을 더하고(주소는 그대로) `popstate`가 오면 닫는다. 버튼·Esc·바깥으로 닫으면 더한 칸을 `history.back()`으로 되돌려 다음 뒤로 가기가 페이지를 제대로 떠난다. 열림→닫힘이 바뀔 때만 다뤄서 개발 모드(StrictMode)에서도 엇갈리지 않는다.
- **구현(2026-11-20):** 고정형은 `BottomSheet`(서버 컴포넌트), 모달형은 `ModalSheet`(클라이언트, `<dialog>` + `showModal()`). 포커스 가두기·Esc·포커스 돌려주기·뒤 화면 막기는 `<dialog>`가 하고, 바깥(어두운 곳)을 눌러도 닫힌다. 모달형은 `open`/`onClose`로 쓰는 쪽이 상태를 가진다. 긴 내용은 스크롤 영역만 스크롤되고, 그 영역은 키보드로 들어가 스크롤할 수 있다(`tabIndex={0}`).
- **스토리:** 고정형, 모달형(짧은 내용/긴 내용).

## 지도

### SantaMap
- **역할:** 세계 지도, **자정선**(지금 막 12월 25일 0시가 된 경도, 세로선), 들른 도시(작은 금색 점), 산타 표시, 우리 동네 표시. 경로 선은 그리지 않는다.
- **결정 (2026-11-22):** 도착 시각이 경도로만 정해져서 실제 경로(661곳)는 남북으로 크게 튄다(하룻밤 약 105만 km, 3,000km 넘는 구간 141개). 경로 선(실선·점선)을 그리면 지도가 엉킨 실타래가 되고, 대권으로 날면 산타가 몇 초 만에 지도를 가로지른다. 처음 정한 "먼 구간은 사라졌다 나타나기"는 재 보니 산타가 여정의 89% 동안 안 보여서 버렸다. **산타는 비행 중 자정선을 탄다**: 경도 = 자정선(1시간에 서쪽으로 15도), 위도 = 두 도시 사이를 진행률만큼. 도착 시각에 자정선이 그 도시에 닿으므로 정확히 도착하고, 지도를 가로질러 튀지 않는다. 계산은 `santaAt`(위치)과 `midnightLongitude`(선)에 있다. 화면 시안(1안)의 경로 선 그림은 이 결정으로 바뀐다.
- **위도 부드럽게 (결정 2026-11-22):** 한국처럼 도시가 촘촘한 곳(25분에 261곳)에서 산타가 1~6초마다 위아래로 떨렸다(데모 `speed=60`에서 진동처럼 보임). `smoothLat`이 "가까운 위도끼리만" 5분 동안 평균한다(위도 차이 8도 기준 가우스 가중치 × 시간 삼각형 가중치, 양방향 필터). 그냥 평균하면 런던 옆 서아프리카처럼 남북으로 먼 도시가 섞여 도착 순간 산타가 런던에서 93px 벗어났다. 결과(세계 지도 확대 1): 한국 위 1px 넘는 흔들림 137번 → 8번, 운영 화면에서 0.05초마다 잰 흔들림 90번 → 21번, 도착 순간 어긋남 중앙값 3px·상위 10% 9px. 한국을 지나는 동안 같은 경도의 다바오·딜리(남위 9도)에 들르는 큰 움직임은 실제로 들르는 것이라 그대로 둔다.
- **상태:**
  - 불러오는 중(지도 자리만, 글자는 이미 보임)
  - 타일 지도(밤/낮)
  - 윤곽 지도(OpenFreeMap 실패·응답 없음 10초, `docs/spike-map-fallback.md`)
  - 지도 없음(지도 JS 실패, 글자만: "지도를 불러오지 못했어요. 산타 소식은 위에서 계속 볼 수 있어요.")
  - 산타 따라가기 켬/끔
  - 출발 전·끝난 뒤에는 **지도를 불러오지 않는다.** 그 자리에 `NorthPoleScene`을 보여준다(아래, 결정 2026-11-17). 데모 모드는 시각을 이브 밤으로 옮기므로 늘 지도가 보인다
- **토큰:** `--map-*`(MapLibre 스타일에 CSS 변수 값을 읽어 넣는다), `santa`, `gold`/`map-route`.
- **접근성:** 지도 캔버스는 화면 낭독기에 숨기고, 위치는 `SantaLocationBanner`의 `aria-live` 문장으로 알린다(CLAUDE.md). 지도 조작 버튼이 있으면 모두 44px.
- **로직:** `santaAt`, `useClock`(프레임 보간), `maplibre-gl` 동적 import(첫 화면 번들에 넣지 않는다), `setWorkerUrl`, 지도 밝기(`useMapTone`).
- **스토리:** 밤/낮 타일, 윤곽 지도, 지도 없음, 데모 시각 고정(`?demo=` 대신 시계를 고정하는 decorator).
- **확인:** 4주차 끝(12/6)까지 실제 저사양 폰으로 FPS 측정(1주차에 남긴 일, 12/14 베타 전).
- **구현(2026-11-22, `src/components/map/`):** `SantaMap`은 경로(`useRoute`)와 시계 읽기 함수(`useClock`)를 받는다. 스타일은 positron(55개 레이어)을 쓰지 않고 OpenFreeMap 벡터 타일에 우리 스타일(육지·바다·국경 2, 자정선·들른 도시 = 6개 레이어, `mapStyle.ts`)을 입힌다. 색은 `--map-*` 토큰을 읽는다. 지도 JS·CSS는 `import()`로 받고 출발 10분 전부터 미리 받는다(첫 화면 111 kB, 지도 JS는 별도 1.1 MB). 산타·우리 동네(흰 점 + 빨간 테두리, 들른 도시 금색 점과 구분)는 DOM 표시. 지도를 끌면 따라가기가 멈추고 "산타 따라가기" 버튼이 나온다. 지도 칸은 `aria-hidden`이고 캔버스는 Tab으로 가지 않는다(`tabindex=-1`). 출처는 지도 밖 글자(`MapAttribution`). MapLibre CSS가 지도 칸을 `position: relative`로 바꾸므로 자리 잡기는 바깥 칸이 하고 지도 칸은 `h-full w-full`.

### MapAttribution
- **구현(2026-11-22):** 타일 지도 "© OpenFreeMap © OpenMapTiles © OpenStreetMap · 도시 GeoNames", 윤곽 지도 "Made with Natural Earth · 도시 GeoNames". 지도가 그려진 뒤에만 보인다.
- **역할:** 지도 위 짧은 출처. 타일 지도는 "© OpenFreeMap © OpenMapTiles © OpenStreetMap", 윤곽 지도는 "Made with Natural Earth".
- **토큰:** `text-attribution`, `map-attribution`.
- **접근성:** 링크로 두면 44px 확보가 어려우므로 글자만 두고, 링크는 설정의 `AttributionBox`에 둔다.

## 메인

### SantaLocationBanner
- **역할:** 지도 위 "지금 산타는 ○○ 상공" 한 줄과 "다음 도착: 부산, 19분 뒤".
- **상태:** 출발 전("산타는 북극에서 출발 준비 중"), 도시 방문 중, 비행 중, 끝난 뒤("산타는 북극으로 돌아갔어요").
- **토큰:** 알약 `bg-surface` `shadow-float` `text-body`, 아래 줄 `map-text` `text-caption`.
- **접근성:** `aria-live="polite"`. 비행 중에는 문장이 자주 바뀌지 않게 **도시가 바뀔 때만** 갱신한다(1초마다 읽히면 화면 낭독기가 시끄럽다).
- **로직:** `santaAt`, `useNow`, 위치 문장 만들기(순수 함수, 아래 "로직" 참고).
- **스토리:** 상태 4개 × 밤/낮 지도.

### CountdownCard
- **역할:** 고정형 시트의 내용. "서울 마포구까지" + "동네 바꾸기", 남은 시간, 도착 예정 시각.
- **상태:**
  - 불러오는 중(서버 렌더, 시각 없음)
  - 동네 안 고름(서울 기준으로 보여주고 "동네 고르기"를 강조)
  - 출발 전, 하루 넘게 남음("37일 2시간")
  - 하루 안("3시간 12분")
  - 1시간 안("27분"), 1분 안("1분 이내")
  - 도착("산타가 우리 동네에 왔어요"), 지나감("산타가 다녀갔어요")
- **토큰:** `text-countdown` `font-display`, `text-body`, `ink`, `ink-soft`.
- **접근성:** 남은 시간은 1초마다 읽지 않는다(`aria-live` 없음). 도착 순간만 `SantaLocationBanner`에서 알린다.
- **로직:** `timeUntil`, 남은 시간·도착 시각 표기(순수 함수), `useHome`. 고른 동네를 읽기 전(서버 렌더·첫 화면)에는 `homeName`이 null이라 "우리 동네까지".
- **스토리:** 상태별, 큰 글씨(줄바꿈 확인), 고대비.
- **"지금은 서울 기준이에요" 안내 (2026-11-22):** 서버 화면에도 늘 넣어 두고, 동네를 고른 사람은 `<head>` 스크립트(`HOME_BOOT_SCRIPT`)가 켠 `<html data-home="chosen">`으로 처음부터 숨긴다. React가 뜬 뒤 안내가 생기거나 사라지며 화면이 밀리지 않게.
- **구현(2026-11-21):** 상태는 `homeCountdown`(`src/lib/santa/countdown.ts`)이 정한다. 도착 뒤 5분(`ARRIVED_FOR_MS`) 동안 "산타가 왔어요!", 그 뒤 "다녀갔어요". 시각을 모르는 첫 렌더에도 같은 높이를 잡아 둔다(레이아웃 이동 방지).

**메인 표시 컴포넌트 공통(2026-11-21):** `SantaLocationBanner`·`CountdownCard`·`JourneyProgress`는 현재 시각을 `now` prop으로 받는다. `useNow()`는 메인 화면 컨테이너 한 곳에서만 부른다. 그래서 스토리에서 시각을 고정해 장면별로 볼 수 있다. 한국어 줄바꿈은 `break-keep`(띄어쓰기에서만 줄바꿈), 위치 알약은 `text-balance`로 줄 길이를 고르게 한다.

### NorthPoleScene (북극 마을)
- **결정 (2026-11-17):** 메르카토르 지도는 북극(위도 약 85도 위)을 그리지 못한다. 산타가 북극에 있는 동안은 지도 대신 북극 마을 그림을 보여준다. 다른 안이던 "지도 위쪽 끝에 표시"는 산타가 잘 안 보이고, "지구본 지도"는 디자인 전체가 바뀌고 성능 위험이 커서 MVP 뒤 검토 거리로 남겼다.
- **역할:** 지도 자리를 채우는 북극 마을 그림과 한 줄 안내. 시안 "3. 시즌 전 — 데모 모드"의 그림을 쓴다.
- **상태:**
  - 출발 전: "북극 마을 · 선물 포장 중", 출발까지 남은 시간("12월 24일 밤 7시 29분, 키리티마티에서 출발해요"), "이브 밤으로 미리 보기"(데모)
  - 끝난 뒤: "산타가 북극으로 돌아갔어요", "다시 보기"(데모)
  - 미리 보기 버튼(2026-11-22): `onPreview`가 있을 때만. 아주 작은 화면(320×568, 320×640 큰 글씨)에서는 버튼만큼 그림이 거의 사라진다(글자·버튼이 그림보다 중요해서 그대로 둠)
- **바뀌는 순간:** 첫 도착 시각에 지도로 바뀐다. 이때 지도 JS를 처음 불러오므로, 출발 몇 분 전부터 미리 불러 둔다. 움직임 줄이기가 켜져 있으면 전환 애니메이션 없이 바꾼다.
- **아래 카드는 그대로:** 출발 전에도 `CountdownCard`(우리 동네까지 남은 시간), 도착 순서(예정 목록), 동네 고르기, 설정, 공유는 모두 동작한다.
- **토큰:** `night`, `gold`(별), `santa`, `text-body`, `map-text`.
- **접근성:** 그림은 `role="img"` + 설명("북극 마을에서 출발을 준비하는 산타"), 남은 시간은 글자로 따로 보여준다.
- **성능:** 출발 전 방문(공개 전 방문 대부분)은 지도 JS를 받지 않으므로 첫 화면이 가장 가볍다.
- **스토리:** 출발 전, 끝난 뒤, 큰 글씨.
- **배치 (2026-11-22):** 위에 글자, 아래 남은 칸에 그림(겹치지 않음). 예전에는 그림이 칸 전체를 채우고 글자가 떠 있어서, 아래 카드가 커지자 작은 화면(320×568)에서 글자가 산타 그림을 덮었다. 그림 칸 아래 24px은 카드가 겹쳐 올라오는 곳이라 비운다.
- **구현(2026-11-21):** `phase`("before"/"after")와 `now`를 받는다. 지도와 그림 중 무엇을 보일지는 메인 화면 컨테이너가 `santaAt`의 상태로 정한다. 색은 늘 밤 그림이라 `--scene-*` 토큰(design-tokens.md)을 쓴다. 글자는 SVG 밖 HTML이라 큰 글씨 모드를 따른다. "이브 밤으로 미리 보기"·"다시 보기"(데모) 버튼은 5주차 데모 모드 때 붙인다.

### JourneyProgress
- **역할:** "산타의 여정 18%" 막대, 출발·끝 시각, "도착 순서 보기".
- **토큰:** `line`(바탕), `santa`(채움), `text-caption`.
- **접근성:** `role="progressbar"` + `aria-valuenow`/`aria-valuetext`("전체 여정의 18%"). 막대 색은 바탕과 3:1 이상(토큰 테스트가 검사).
- **로직:** 진행률 = (지금 − 첫 도착) ÷ (마지막 도착 − 첫 도착).
- **출발 전에도 보인다 (결정 2026-11-22):** 빈 막대와 "산타의 여정 · 출발 전", 출발·끝 시각, "도착 순서 보기". 서버는 지금이 출발 전인지 여정 중인지 몰라서, 단계마다 카드 높이가 다르면 시각을 안 뒤 카드가 커지며 화면이 밀렸다(여정 중 0.064, 320px 큰 글씨 끝난 뒤 0.190). 시각을 모르는 첫 화면에서도 같은 높이(시각 줄 자리 포함)를 잡아 둔다.

## 시트 내용

### ArrivalList (도착 순서)
- **역할:** 지나간 도시, 지금 위치, 다음 도시를 한국 시각으로. 우리 동네 행 강조. "다음 도시 더 보기".
- **행 상태:** 지나감(`ink-faint`), 지금(`now` + 산타 점), 곧 도착("19분 뒤"), 우리 동네(`highlight` 바탕).
- **출발 전:** 지나간 도시가 없으므로 첫 도착(키리티마티)부터 **예정 목록**으로 보여주고, 제목 아래에 "12월 24일 밤 7시 29분 출발 예정"을 쓴다.
- **접근성:** `<ol>`. 우리 동네 행은 글자로도 "우리 동네"라고 쓴다(색만으로 구분하지 않는다). 시트가 열리면 지금 행이 보이게 스크롤.
- **로직:** 경로에서 지금 앞뒤 N개 고르기(순수 함수), 한국 시각 표기("밤 12시 32분", "새벽 1시 14분").
- **스토리:** 출발 직후, 한국 근처(시안과 같은 장면), 우리 동네 지난 뒤.
- **구현(2026-11-22):** `arrivalRows`(`src/lib/santa/arrivals.ts`)가 지난 도시 2곳·지금·다음 도시 6곳을 고르고, 우리 동네가 더 뒤면 "⋯ 도시 N곳 ⋯"을 건너 맨 끝에 붙인다. "다음 도시 더 보기"는 10곳씩 늘린다. "지금" 줄 글자는 `santaPlace`(위치 문장의 가운데, "후쿠오카 상공"). 시트가 열려 있을 때만 그리고, 열면 지금 줄(출발 전에는 첫 예정 도시)로 스크롤한다. 출발 전에는 여정 막대가 없어서 카운트다운 아래 "도착 순서 보기" 버튼을 따로 두고, 전체 경로는 시트를 열 때 받는다.

### NeighborhoodPicker (동네 고르기)
- **역할:** 시·군·구 검색(초성 지원), 결과마다 도착 시각, 지금 고른 동네 표시, "내 위치로 찾기", 저장 안내.
- **상태:** 빈 검색어(지금 동네만), 결과 있음, 결과 없음("찾는 동네가 없어요"), 위치 찾는 중, 위치 권한 거부, 위치를 못 찾음.
- **토큰:** 입력창 `rounded-input` `border-link`(포커스), 결과 `surface-muted`(선택됨), `ink-soft`.
- **접근성:** `<label>` 있는 `<input type="search">`, 결과 개수를 `aria-live`로 알림("찾은 동네 2곳"), 결과는 버튼(`aria-pressed`), 56px 이상.
- **로직:** 초성 검색(순수 함수), 가장 가까운 시군구(순수 함수), `SIGUNGU` 데이터, `useHome`(localStorage, 서버로 보내지 않는다).
- **스토리:** 상태별, "ㅁㅍ" 검색(마포구·목포시), 큰 글씨.
- **구현(2026-11-22):**
  - **검색:** `matchChosung`(`src/lib/hangul.ts`)이 초성("ㅁㅍ"), 완성 글자, 섞어 치기, 치는 중인 마지막 글자("모"→목포, "맢"→마포)를 찾는다. `searchNeighborhoods`는 이름이 검색어로 시작 → 이름 가운데 → 시도 이름("서울", "강원") 순, 같으면 이름 가나다순.
  - **내 위치로 찾기:** 하나를 바로 고르지 않고 가까운 3곳을 거리와 함께 보여주고 사람이 고른다(대표점 거리라 경계 근처는 이웃 동네가 먼저 나올 수 있다). 대표점에서 먼 섬(가거도·흑산도·연평도·추자도·독도 등)은 섬 위치를 따로 둬서 제 동네가 먼저 나온다. 가장 가까운 동네가 150km보다 멀면 "한국 밖". 위치는 계산에만 쓰고 보내지 않는다.
  - **고르면:** 바로 저장하고 시트를 닫는다. 카운트다운·도착 순서·지도 표시가 새 동네로 바뀐다. 지도는 다시 만들지 않고 우리 동네 표시만 옮긴다.
  - **불러오기:** 시군구 목록(gzip 약 5.6 kB, 경로 데이터와 같은 파일)은 시트를 열 때 받는다(`useNeighborhoods`). 고른 동네는 이름·좌표째 저장해서(`home.ts`) 첫 화면은 목록 없이 바로 카운트다운을 보여준다.
  - **저장(`useHome`):** localStorage `where-is-santa:home`에 `{v, id, name, lat, lon}`. 읽을 때 모양·범위를 검사하고 틀리면 기본 동네. 도착 시각은 저장하지 않고 좌표로 다시 계산한다. 저장이 막힌 브라우저(사생활 보호 모드)는 이번 방문 동안만 기억한다. 다른 탭에서 바꾸면 따라 바뀐다.
  - **움직임 (사람 검토 2026-11-22):** 검색 결과가 너무 갑자기 생기고 사라진다는 의견. 새로 생긴 동네만 0.18초 동안 서서히 나타나고(4px 올라옴, `.list-enter`), 사라지는 동네는 바로 빠진다(사라짐 효과는 새 의존성이나 View Transitions가 필요하고 빠른 입력에서 버벅일 수 있어 하지 않음). 결과 칸은 3줄 높이(11.5rem)를 늘 잡아 두어 결과 0~3곳 사이에서는 "내 위치로 찾기"가 움직이지 않는다. 움직임 줄이기면 애니메이션을 끈다.
  - **첫 화면:** 서버 렌더와 첫 화면은 저장 값을 모르므로 "우리 동네까지"로 그리고 "동네 고르기" 버튼은 저장 값을 읽은 뒤에 보인다(새로고침 때 잠깐 "서울 중구"가 보이지 않게).

### SettingsPanel
- **역할:** 지도 밝기, 큰 글씨, 고대비, 움직임 줄이기, 출처. 소리는 소리 기능을 만들 때 넣는다(누를 때 아무 일도 없는 스위치는 두지 않는다, 기획서 결정 2026-11-22).
- **상태:** 기본값, 각 설정 켬. 움직임 줄이기는 기기 설정(`prefers-reduced-motion`)이 켜져 있으면 기본으로 켜짐.
- **로직:** `useSettings`(localStorage). 설정은 `<html>` 속성(`data-map-tone`, `data-text-size`, `data-contrast`)으로 바로 반영한다(`docs/design-tokens.md`).
- **스토리:** 기본, 모두 켬.
- **구현(2026-11-22):**
  - **열기:** 메인 오른쪽 위 설정 버튼(시안처럼 위치 알약 오른쪽, 출발 전·끝난 뒤에도 같은 자리). 북극 마을 장면은 첫 줄("산타 출발까지", "산타가 북극으로 돌아갔어요")을 버튼과 같은 높이 줄에 두고 양옆을 비운다. 그 아래 큰 카운트다운은 버튼 아래에서 시작한다(좁은 화면 320~360px에서 카운트다운이 버튼에 가려졌다).
  - **저장(`useSettings`):** localStorage `where-is-santa:settings`에 `{v, mapTone, largeText, highContrast, reduceMotion}`. 칸마다 검사하고 틀린 칸만 기본값. 고른 동네와 같은 저장 도우미(`src/hooks/storedValue.ts`)를 쓴다.
  - **움직임 줄이기:** 저장 값이 없으면(null) 기기 설정을 따른다. 기기와 다르게 바꾸면 그 값을 저장하고, 다시 기기와 같게 바꾸면 null로 돌아간다. 설명: "기기 설정을 따라 켜져 있어요", "기기 설정과 달리 꺼 두었어요".
  - **첫 화면:** `SETTINGS_BOOT_SCRIPT`가 React보다 먼저 속성을 켠다(큰 글씨로 새로고침해도 글자가 나중에 커지지 않는다). 스크립트가 `settingsAttributes`와 같은 속성을 켜는지 테스트가 실제로 실행해 확인한다.

### AttributionBox
- **역할:** 지도·데이터 출처 상자. OpenFreeMap, OpenMapTiles, OpenStreetMap 기여자, GeoNames, 국가데이터처 SGIS, Natural Earth.
- **토큰:** `surface-muted`, `text-fine`, `link`.
- **접근성:** 링크 글자 대비 4.5:1 이상(토큰 테스트가 검사). 줄 사이 간격을 넉넉히 둬 링크끼리 붙지 않게 한다.
- **구현(2026-11-22):** 링크는 새 창으로 열고 화면 낭독기에 "(새 창)"을 읽힌다. 국가데이터처 SGIS는 링크 없이 이름만.

## 공유·데모 (5주차)

### SharePanel
- **역할:** 공유 카드 미리보기, 인사말 입력(40자), "링크 복사", "메신저로 보내기".
- **상태:** 기본, 인사말 입력 중(글자 수), 40자 초과, 복사됨("복사했어요"), 복사 실패, 공유 기능 없는 브라우저(메신저 버튼 숨김).
- **접근성:** `<label>`이 있는 `<textarea>`, 글자 수는 `aria-describedby`, 복사 결과는 `aria-live`.
- **로직:** 공유 링크 만들기(받는 사람 동네 기준으로 열림), OG 이미지 라우트, Web Share API.
- **구현(2026-11-27):**
  - **링크:** `/s/<보낸 사람 동네 id>?m=<인사말>`(`sharePath`). 링크를 연 화면은 받는 사람의 동네 기준이고, 처음에 "친구가 보낸 산타 소식" 시트(`ReceivedPanel`)를 띄운다. 동네를 이미 골랐고 인사말이 없으면 띄우지 않는다. 없는 동네 id는 첫 페이지로.
  - **미리보기 그림(결정 2026-11-26):** 남은 시간이 아니라 **도착 시각**("서울 마포구에 산타가 오는 시간 · 12월 24일 밤 12시 32분"). 메신저가 미리보기 그림을 오래 저장해 남은 시간은 금방 틀린다. 그래서 동네 256곳 그림을 빌드 때 미리 만든다(`/og/[id]`, 정적, 새 의존성 없이 Next 내장 `next/og`). 첫 페이지(/)는 북극 출발 시각 카드(`opengraph-image`).
  - **인사말(결정 2026-11-26):** 그림이 아니라 미리보기 제목(`og:title`)과 받는 화면에 보인다. 그림에 넣으면 요청마다 그려야 하고, 누구나 우리 주소로 아무 글자 그림을 만들 수 있다. 40자는 사람이 세는 글자(이모지 하나 = 1자, `Intl.Segmenter`). 받는 쪽도 같은 규칙으로 다시 다듬는다(`cleanGreeting`: 제어 문자·줄바꿈 정리, 40자에서 자름). 공유 페이지는 검색에 싣지 않는다(`noindex`).
  - **카드 그림 한 벌:** `ShareCardArt`를 서버(1200×630 PNG)와 공유 시트 미리보기가 같이 쓴다. 크기는 `u()`로 받아 서버는 px, 화면은 컨테이너 너비 비율(cqw).
  - **글꼴:** 그림 엔진은 woff2를 못 읽어서, 그림에 쓰는 글자만 빌드 때 Google Fonts에서 TTF로 받는다(`src/app/og/fonts.ts`, Jua·IBM Plex Sans KR). `next/font`와 같은 곳·같은 시점이라 빌드에 새 외부 의존은 없다.
  - **동네 고르기:** 공유·인사말 시트의 "우리 동네 고르기"는 같은 시트 안에서 내용을 바꾼다. 시트를 닫자마자 다른 시트를 열면 닫을 때 되돌린 방문 기록 칸(`history.back()`, 비동기)이 새 시트 칸까지 빼서 새 시트가 바로 닫힌다.
  - **앱 아이콘(결정 2026-11-26):** 지도·카드의 산타 표시(`src/app/icon.svg`, 아이폰용 `apple-icon` 180px). 전에는 아이콘이 없어 창 있는 브라우저가 `/favicon.ico` 404를 받았다.
  - **작은 화면:** 시트에 버튼이 늘어 320×568에서 시트가 "이브 밤으로 미리 보기"를 덮었다. 위쪽 칸에 최소 높이(16rem)를 두고 화면 높이를 최소값으로 바꿔, 아주 작은 화면·큰 글씨에서는 시트가 아래로 밀리고 페이지가 스크롤된다.

### DemoPanel · DemoBadge
- **역할:** 시즌 전 화면. 출발까지 남은 시간, 시간 흐름 선택(`SegmentedControl`), "이브 밤으로 시간 이동". 데모 중에는 메인 위에 `DemoBadge`("데모 모드").

- **구현(2026-11-22):**
  - **여는 곳:** 북극 마을의 "이브 밤으로 미리 보기"(출발 전)·"다시 보기"(끝난 뒤), 데모 중에는 맨 위 띠의 "바꾸기". 진짜 이브(출발 24시간 전~여정 끝)에는 권하지 않는다(`demoOffered`).
  - **시간 이동:** 우리 동네 도착 20분 전, 기본 1초=1분(결정 2026-11-22: 20초 뒤 산타가 우리 동네에 온다). 시간 흐름은 실제 속도·1초=1분·1초=10분.
  - **데모 중 시트("데모 모드"):** 배속을 바꾸면 지금 데모 시각에서 이어서 흐른다(`retimeDemoClock`, 앞뒤로 튀지 않음). "처음부터 다시 보기", "데모 끝내기"(서버로 보정한 실제 시계로 돌아감).
  - **주소:** 데모 상태를 `?demo=<한국 시각 ISO>&speed=<배속>`로 주소에 남긴다(`demoSearch`, 방문 기록은 늘리지 않음). 새로고침하면 마지막으로 쓴 데모 시각부터 이어진다. 시트가 열려 있으면 시트가 더한 방문 기록 칸 위라, 그 칸이 빠질 때(popstate)까지 미룬다(`src/hooks/sheetHistory.ts`). 이때 늦추지 않고 popstate 안에서 바로 쓴다: Next.js 라우터도 popstate에서 주소를 읽어 나중에 되돌려 쓰기 때문에, 늦추면 우리 주소가 지워졌다.
  - **`DemoBadge`:** 맨 위 띠 "데모 모드 · 1초 = 1분" + "바꾸기". 서버는 주소의 검색어를 모르는 정적 페이지라 띠를 늘 넣어 두고, `<head>` 스크립트(`DEMO_BOOT_SCRIPT`)가 켠 `<html data-demo="on">`이 없으면 숨긴다. 데모 주소로 들어와도 띠가 나중에 생기며 화면이 밀리지 않는다(새로고침 CLS 0.002). 띠만큼(52px) 위쪽 칸(지도·그림)이 줄어든다.
- **접근성:** 데모 모드 표시는 글자로(색만으로 구분하지 않는다).
