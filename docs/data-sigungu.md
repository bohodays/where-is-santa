# 국내 시군구 데이터

동네 선택과 "우리 동네 도착" 계산에 쓰는 시군구 256곳의 대표 좌표. 결과 파일은 `src/lib/santa/sigungu.ts`(자동 생성)다.

## 결정 (2026-11-10)

| 항목 | 결정 |
|---|---|
| 원본 | [국가데이터처_SGIS 행정구역 통계 및 경계](https://www.data.go.kr/data/15129688/fileData.do) (공공데이터포털) |
| 이용 조건 | **이용허락범위 제한 없음** (공공데이터포털 표기). 의무는 아니지만 README와 화면에 출처를 적는다 |
| 기준 시점 | 2025년 2분기(2025-06-30) 시군구·행정동 경계, 좌표계 UTM-K(EPSG:5179) |
| 단위 | 시군구 + 일반구 (예: "수원시 장안구") |
| 대표점 | 시군구 영역 안쪽의 점(`mapshaper -points inner`), WGS84로 변환, 소수 넷째 자리(약 11m) |
| 변환 도구 | mapshaper 0.7.97(MPL-2.0)을 `npx`로 실행. `package.json`에는 넣지 않는다 |

### 비교했던 후보

| 후보 | 이용 조건 | 쓰지 않은 이유 |
|---|---|---|
| 국토교통부 (센서스경계) 시군구경계 | 이용허락범위 제한 없음 | SGIS와 같은 센서스 경계이고 갱신이 연 1회로 더 드묾 |
| GeoNames KR (ADM2) | CC BY 4.0 | 이름에 '시'·'군'이 빠진 경우가 많고, 군위군의 소속 시도가 옛 정보(경북), 일반구 없음 |
| SGIS 단계별주소조회 API | 공공누리 2유형(상업적 이용금지) | 조건이 더 좁고, 이브 밤에 외부 API를 부르게 된다 |
| GADM 기반 지도 | 비상업만, 재배포 금지 | 사용 불가 |

## 기준 시점 이후 변경

`scripts/sigungu-changes.json`에 근거 링크와 함께 적는다. 없어진 시군구를 빼고, 새 구는 SGIS 행정동 경계를 묶어 대표점을 구한다. 변환 스크립트는 없어지는 시군구의 행정동이 새 구에 **빠짐없이 한 번씩** 들어갔는지 검사한다.

| 시행일 | 변경 | 결과 |
|---|---|---|
| 2026-02-01 | 화성시 4개 일반구 설치 | 화성시 → 만세구(10개 동), 효행구(5), 병점구(5), 동탄구(9) |
| 2026-07-01 | 인천 행정체제 개편 | 중구·동구·서구 → 제물포구(18개 동), 영종구(5), 검단구(7), 서해구(16) |

결과: 252곳 − 4곳 + 8곳 = **256곳**. 새 구의 id는 SGIS 코드가 아직 없어서 `x-`로 시작한다(예: `x-incheon-jemulpo`).

## 다시 만드는 법

1. 공공데이터포털에서 "국가데이터처_SGIS 행정구역 통계 및 경계"를 받아 저장소 바로 아래 `SGIS/`에 푼다. (`.gitignore` 대상, 약 400MB)
2. 기준 시점 이후 행정구역이 바뀌었으면 `scripts/sigungu-changes.json`에 추가한다. 새 경계 데이터에 이미 반영된 변경은 지운다.
3. `node scripts/build-sigungu.mjs` 실행 후 `npm test`로 `src/lib/santa/sigungu.test.ts`를 확인한다.

## 검증 (2026-11-10)

- 변환 스크립트 검사: 행정동 배정 누락·중복 없음, 개수 256, 좌표가 한국 범위 안
- GeoNames 좌표와 비교(이름이 맞는 214곳): 거리 중앙값 1.7km, 90%가 7.6km 이내
  - 15km 넘게 차이 난 곳은 대표점 기준 차이(GeoNames는 군청 소재지)이거나, GeoNames에 없는 구가 다른 도시의 같은 이름 구와 비교된 경우였다(포항 북구·남구)
- 도착 시각: 모든 시군구가 한국 시각 12월 25일 0시 16분(울릉군)~0시 42분(옹진군) 사이

## 알려진 한계

- **섬 지역:** 대표점이 가장 큰 섬 위에 찍힌다. 옹진군은 백령도(동경 124.67도)라서, 동쪽 섬(영흥도 등)에 사는 사람에게는 도착 시각이 최대 약 6분 늦게 보인다. 필요하면 섬 지역만 읍면 단위로 나눈다.
- 경계 데이터가 바뀌면(반기 갱신) 새 경계에 반영된 변경과 `sigungu-changes.json`이 겹치지 않게 정리해야 한다.
